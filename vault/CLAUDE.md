# CLAUDE.md — 이 볼트에서 LLM이 일하는 법

이 폴더는 개인 지식 위키(Obsidian 볼트)다. 소유자: 전고체 전지 전극공정 R&D 엔지니어.
목적: 원본을 매번 재조회하는 RAG가 아니라, 정리된 위키를 읽고 지식이 누적되는 LLM 위키.

## 읽기 경로 (토큰 절약 — 반드시 이 순서)

1. `INDEX.md` — 도메인 지도 (~1k 토큰)
2. `Me.md` — 사용자 프로필 (답변 톤·전문성 조정)
3. 해당 도메인의 `MOC_*.md` 1개
4. MOC가 가리키는 개별 노트 3~5개만

볼트 전체를 스캔하지 않는다. 검색이 필요하면 파일명·frontmatter(topic, tags) 우선.

## 쓰기 규칙

- **새 노트는 `000. INBOX/`에만 생성**한다. 분류(ingest) 세션에서만 다른 폴더로 이동.
- **frontmatter 필수** — 스키마:
  - `type`: note | lecture | clipping | weekly | project | patent | reference | concept | moc
  - `status`: raw(수집) → draft(정리 중) → refined(정본). 승급은 사람 승인 후.
  - `domain`: 시사 | 업무 | 학습 | 투자 | 프로젝트 | 커리어 | 일상
  - `topic`(한 줄), `created`, `modified`, `source`, `related`(링크 목록), `tags`
  - lecture는 `course`, `speaker`, `venue` 추가. 값은 enum 그대로(한글 변형 금지).
- **명명**: 지식 노트=서술형 제목(버전 접미 금지) / 이벤트성=`YYMMDD_이름` / 위클리=`YYWnn_위클리`. `무제`, `.md.md` 금지.
- **위키링크는 실존 노트에만** 건다. 없는 개념을 링크하고 싶으면 `related`에 후보로만 적는다.
  같은 개념이 노트 2개 이상에서 필요해지면 `700. 개념/`에 concept 노트를 만들고 그때 링크로 승격.
- **정본 1개 원칙**: 기존 정본이 있으면 새 파일을 만들지 말고 그 노트에 통합한다. 초안·구버전은 `900. 아카이브/`로.
- 수정 시 `modified` 갱신. 큰 변경은 `INDEX.md`의 '최근 추가/변경'에 한 줄.

## 유지보수 루틴 (요청 시 수행)

- **ingest** ("INBOX 비워줘"): INBOX 각 노트에 스키마 적용 → 개명 → 대상 폴더 제안 → 승인 후 이동 → 해당 MOC에 등록.
- **lint** ("위키 점검해줘"): 고아 위키링크, frontmatter 누락/이탈, status=raw 2주 이상 정체, INBOX 잔류물을 표로 보고. 수정은 승인 후.
- **query**: 위 읽기 경로를 따르고, 답변에 근거 노트를 `[[제목]]`으로 인용한다.

## 금지·주의

- API 키, 자격증명, 비밀번호를 노트에 저장하지 않는다. 발견 시 즉시 사용자에게 보고.
- `900. 아카이브/`는 읽기 전용 — 수정·삭제 금지, 이관도 복사로만.
- `999. 일상/`은 개인 영역 — 명시 요청 없이 색인·인용하지 않는다.
- 조직·인사 관련 민감 메모는 위키 본문에 두지 않는다 (개인 영역으로 분리 제안).
