# B7. 골든 버터플라이 (Golden Butterfly)

```yaml
name: 골든 버터플라이 (Golden Butterfly Portfolio)

origin: >
  "Tyler"(Portfolio Charts 운영자), 2015년 제안. 완전 공개.
  - https://portfoliocharts.com/portfolios/golden-butterfly-portfolio/
  - https://portfoliocharts.com/2015/09/22/catching-a-golden-butterfly/

category: B  # 목표가치·리밸런싱형

assets: >
  미국 총주식시장(예 SPY/VTI) 20%, 스몰캡가치(예 IWN/VBR) 20%, 장기국채(TLT 20+Y)
  20%, 단기국채(SHY 1-3Y) 20%, 금(GLD) 20%. 영구 포트폴리오의 4축(주식/장기채/금/
  현금)에서 현금 대신 단기국채를 넣고, 주식 20%p를 스몰캡가치로 대체해 성장 팩터를
  가미한 구조. lot_size 정수 주 가정.

state: 자산별 current_weight (Decimal).

params: >
  target_weight 20%×5(고정), rebalance_method(연1회 캘린더 또는 밴드 15%~25%
  — Portfolio Charts는 두 방식 모두 언급), 원금.

schedule: >
  evaluation_frequency=연1회(기본) 또는 일별 밴드 감시. trigger_condition=
  리밸런싱일 도달 OR 자산비중이 15% 미만·25% 초과로 이탈(밴드 방식 채택 시).

cycle_definition: >
  포지션 생애주기 없음(영구 유지). trigger=리밸런싱 시점, resets=5자산 비중을
  20%로 재설정, carries=없음.

mode_transition: 상태기계 없음.

order_roles: REBALANCE_BUY/REBALANCE_SELL — 5자산 동시 재조정.

fill_interaction_rules: 해당 없음.

rounding: 정수 주 내림 외 특이사항 없음

rules: |
  # 연1회 방식
  if today == annual_rebalance_date:
      for asset in [us_stock, smallcap_value, long_bond, short_bond, gold]:
          rebalance_to(asset, 0.20)

  # 밴드 방식(대안)
  if any(weight[a] < 0.15 or weight[a] > 0.25 for a in assets):
      for asset in [us_stock, smallcap_value, long_bond, short_bond, gold]:
          rebalance_to(asset, 0.20)

orders: 리밸런싱일 종가 기준 매매 가정.

fee_model: 매매수수료율 파라미터화.

dividend_handling: 배당·이자는 현금으로 유입 후 다음 리밸런싱에 반영.

cash_profile: >
  목표배분에 별도 현금 없음(영구 포트폴리오와 달리 단기국채가 안정성 축을 담당) —
  리밸런싱 대기용 buffer만 일시 존재.

risk_notes: >
  퍼머넌트 포트폴리오 대비 스몰캡가치 팩터 프리미엄으로 성장성을 보완한 만큼 변동성
  이 소폭 상승. Portfolio Charts 자체 백테스트(1987-12-31~2026-07-11) 기준 CAGR
  8.3%, 최대낙폭 -19.9%, Sharpe 1.13 (출처 사이트 수치, 별도 검증 필요). 파산·강제
  손절 조건 없음.

automation: >
  연1회 리밸런싱 자동화 용이. 사람 개입 지점: 밴드 vs 연1회 방식 선택, 스몰캡가치
  ETF의 한국 계좌 접근성(해외 ETF 직접 매매 가능 여부).

backtest_notes: >
  스몰캡가치 지수 데이터가 총주식시장 대비 입수 제한적일 수 있음 — 대체 티커(IWN
  vs VBR 등) 선정 근거를 리포트에 명시. 데이터 시작일이 늦은 자산(IWN 1997년 상장
  등) 때문에 백테스트 구간이 다른 전략보다 짧아질 수 있음.
```
