# B6. 올웨더 (All Weather) — 공개 근사 레시피

```yaml
name: >
  올웨더 (Ray Dalio All Weather) — Tony Robbins판 공개 근사 레시피.
  ⚠️ Bridgewater의 실제 All Weather 펀드(리스크패리티 알고리즘, 레버리지 포함) 원본은
  비공개이며, 여기 기술하는 것은 Dalio가 인터뷰에서 언급한 단순화된 개인투자자용
  근사치임을 명시.

origin: >
  Ray Dalio(Bridgewater Associates)가 Tony Robbins와의 인터뷰에서 제시. Robbins의
  저서 "MONEY Master the Game"(2014)을 통해 공개. 근사 레시피이며 원본 알고리즘
  아님.
  - https://www.optimizedportfolio.com/all-weather-portfolio/
  - https://www.portfolioeinstein.com/tony-robbins-and-ray-dalios-portfolio/
  - https://portfoliocharts.com/portfolios/all-seasons-portfolio/

category: B  # 목표가치·리밸런싱형

assets: >
  주식 30%(VTI 등 총주식시장), 중기국채 15%(IEF 7-10Y), 장기국채 40%(TLT 20+Y),
  금 7.5%(GLD), 원자재 7.5%(DBC 등). 채권 합계 55%로 리스크패리티(채권은 변동성이
  낮아 주식과 동등한 리스크 기여를 위해 명목 비중을 크게 배정)를 근사. lot_size
  정수 주 가정.

state: 자산별 current_weight (Decimal).

params: >
  target_weight(위 5개 자산 dict, 고정), rebalance_method(연1회 캘린더가 통상
  채택되는 방식 — 원 인터뷰는 구체적 주기 언급 없음), 원금.

schedule: >
  evaluation_frequency=연1회(캘린더) 통상. trigger_condition=리밸런싱일 도달.
  (밴드 방식 채택도 가능하나 원 레시피에 명시된 밴드값 없음 — 구현 시 자체 결정.)

cycle_definition: >
  포지션 생애주기 없음(영구 유지). trigger=리밸런싱 시점, resets=5자산 비중 재설정,
  carries=없음.

mode_transition: 상태기계 없음.

order_roles: REBALANCE_BUY/REBALANCE_SELL — 5자산 동시 재조정.

fill_interaction_rules: 해당 없음.

rounding: 정수 주 내림 외 특이사항 없음

rules: |
  if today == annual_rebalance_date:
      for asset, w in target_weight.items():   # 주식30/중기채15/장기채40/금7.5/원자재7.5
          rebalance_to(asset, w)

orders: 리밸런싱일 종가 기준 매매 가정.

fee_model: 매매수수료율 파라미터화.

dividend_handling: >
  배당·이자는 현금으로 유입 후 다음 리밸런싱까지 대기, 리밸런싱 시점에 목표비중에
  흡수(현금 자체는 목표자산이 아님).

cash_profile: >
  목표배분에 현금 없음 — 저비중 현금은 리밸런싱 대기용 buffer로만 일시 존재.

risk_notes: >
  채권 비중(55%)이 높아 금리 급등·인플레 동반 국면(2022년형)에 취약하다는 점이
  실측 사례로 자주 언급됨. 레버리지를 쓰지 않는 근사판이라 Dalio 원 기관용
  버전(레버리지 활용, 목표 변동성 관리)과 리스크 프로필이 다름 — 이 문서 규칙은
  "단순화된 소매투자자 버전"에 한정.

automation: >
  연1회 리밸런싱 자동화 용이. 사람 개입 지점: 리밸런싱 주기 결정, 원자재 ETF(DBC
  등) 한국 상장 대체재 확보 필요 여부.

backtest_notes: >
  원본이 비공개이므로 본 문서 기반 백테스트는 "Dalio 올웨더의 공개 근사"에 대한
  결과이며, 실제 Bridgewater All Weather 펀드 성과와 다를 수 있음을 비교
  리포트에 반드시 명시.
```
