# E1. Lifecycle Investing (생애주기 레버리지 투자)

프레임 개요만 다루는 문서(PLAN.md 지시) — 코어 6종 백테스트 대상 아님. "인생 전체를 하나의 포트폴리오로
보고 레버리지를 시간축에 걸쳐 분산한다"는 아이디어의 이론적 배경을 정형화 스키마 형식으로 요약.

  Way to Improve the Performance of Your Retirement Portfolio* (2010).

## category

E (레버리지 운용 프레임)

## assets

- S&P 500 등 광범위 지수 ETF. 레버리지 수단으로 (a) 증권사 신용거래(마진), (b) 지수 선물,
  (c) 만기가 긴 등가격 근접 콜옵션(LEAPS, deep-in-the-money)을 저자들이 제시.
- 이 프로젝트(MumaeApp/KIS 미국주식 현물 LOC/MOC 중심) 실행 수단과는 거리가 있음 — 신용거래·선물·
  옵션 어댑터가 없어 **1차 구현 대상에서 제외**된 이유이기도 함.

## state

| 변수 | 타입 | 설명 |
|---|---|---|
| `age` / `years_to_retirement` | int | 은퇴까지 남은 기간 (레버리지 축소 경로의 기준) |
| `human_capital_pv` | Decimal | 미래 근로소득의 현재가치 추정치 (이론상 "채권처럼" 취급되는 자산) |
| `target_stock_exposure_ratio` | Decimal | 목표 주식 노출 비율 (레버리지 포함, 아래 params 참조) |

## params

| 파라미터 | 설명 |
|---|---|
| `max_leverage` | 초기(젊을 때) 최대 레버리지 배율 — 저자 권고 **2:1** |
| `target_lifetime_stock_allocation` | 생애 전체 저축의 현재가치 대비 목표 주식 배분 비율 — 저자 예시
  **83%** (이른바 "83/n" 류 규칙. 개인 위험선호에 따라 달라짐, 고정 상수 아님) |
| `glide_path` | 나이가 들수록 레버리지를 줄여나가는 경로 — 초기 200% 주식 노출에서 시작해 목표 비율(예:
  83%)까지 선형에 가깝게 감소 |
| `margin_rate` | 레버리지 조달 비용(신용거래 이자율 또는 선물 내재금리) — 전략 성립에 결정적 변수 |

## schedule

- `evaluation_frequency`: 연 단위(또는 생애 마일스톤 단위) — 일봉 백테스트 성격의 다른 코어 전략과
  시간축 스케일 자체가 다름.
- `trigger_condition`: 나이 증가에 따른 주기적 리밸런싱(레버리지 축소) + 마진콜/추가증거금 발생 시
  강제 디레버리징.

## cycle_definition

- 전통적 의미의 매수-매도 사이클이 아니라 **생애 전체가 하나의 기간**. "사이클 종료"는 은퇴 시점.

## mode_transition

- 대략적 상태기계: `HIGH_LEVERAGE(젊음, 최대 2:1)` → 나이 증가에 따라 점진적으로 →
  `NO_LEVERAGE(목표 비율 도달, 레버리지 없음)` → 이후는 표준 자산배분(예: 나이별 채권 비중 증가)으로
  전환.
- 강제 전이: 마진콜(추가증거금 요구) 발생 시 즉시 포지션 축소 — 저자들은 이 리스크를 레버리지
  배율(2:1은 상대적으로 안전권) 선택으로 관리할 것을 권고.

## order_roles

프레임 수준 문서라 구체 주문 역할은 정의하지 않음(실행 수단이 마진/선물/옵션 중 무엇이냐에 따라
전혀 다른 주문 체계가 필요).

## fill_interaction_rules

해당 없음(프레임 개요).

## rounding

해당 없음(프레임 개요 — 구체 구현 시 결정).

## rules (개념 요약, 의사코드 아님)

1. 개인의 총 자산 = 현재 금융자산 + 미래 근로소득의 현재가치(인적자본). 젊을 때는 인적자본이
   압도적으로 커서, 금융자산만 놓고 보면 "충분히 분산되지 않은" 상태 — 이를 레버리지로 보정.
2. 저자들의 핵심 결론: **표준 생애주기 펀드(TDF, "나이만큼 채권" 규칙)나 100% 주식 투자보다,
   젊을 때 최대 2:1 레버리지로 시작해 나이가 들며 줄여나가는 편이 기대 은퇴자산과 리스크 양쪽에서
   우월**(1871년 이후 미국 데이터 + 1만 회 시뮬레이션 근거). 100% 주식 대비 기대 은퇴자산 +19%,
   전형적 생애주기 펀드 대비 +90% (저자들의 보고 수치).
3. 실행 수단으로 신용거래보다 **선물 또는 만기가 긴 등가격 근접 콜옵션(LEAPS)**을 선호 — 신용거래
   이자율보다 내재금리가 유리한 경우가 많고, 옵션은 손실이 프리미엄으로 제한되어 마진콜 리스크가
   구조적으로 없음.

## orders

프레임 수준이라 구체 주문 유형 정의 없음. (참고: 옵션 방식을 택하면 KIS는 미국 옵션 주문을 별도로
지원해야 하며, 현재 MumaeApp 어댑터 범위 밖.)

## fee_model

레버리지 조달 비용(마진 이자율/선물 콘탱고·백워데이션/옵션 타임밸류 소모)이 사실상의 "수수료"이자
전략 성립 여부를 좌우하는 핵심 변수 — 단순 매매 수수료보다 훨씬 중요.

## dividend_handling

기초지수 ETF 배당은 표준 재투자 가정. 레버리지 조달 수단(선물/옵션)은 배당을 직접 수취하지 않고
가격(베이시스)에 반영되는 방식이 달라 실제 구현 시 별도 처리 필요.

## cash_profile

- 레버리지 사용 구간은 현금 비중이 음수(차입)에 가까운 개념 — 이 프로젝트의 다른 전략들이 가정하는
  "현금 비중"과 성격이 다름.

## risk_notes

- **마진콜/강제청산 리스크**: 신용거래로 구현 시 급락장에서 추가증거금 요구로 강제 청산될 수 있음 —
  저자들은 이 리스크를 완화하려 레버리지 상한을 2:1로 제한하고 선물/옵션(손실 제한)을 권고.
- **인적자본 가정의 취약성**: 이론 전체가 "미래 근로소득이 채권처럼 안정적"이라는 가정에 의존 —
  실직·소득 변동성이 큰 직업군에는 적용이 위험할 수 있다는 비판이 널리 제기됨(review 자료 참조).
- 백테스트가 1871년 이후 미국 시장 데이터에 기반해 생존 편향·미국 예외주의 비판을 받을 수 있음.
- **본 프로젝트와의 접점**: 무한매수법·HFEA 모두 레버리지 ETF를 매개로 한 레버리지 활용이라는 점에서
  Lifecycle Investing의 문제의식(젊을 때 레버리지, 나이 들며 축소)과 사상적으로 연결되나, 실행 방식
  (마진/선물/옵션 vs 3배 레버리지 ETF)이 근본적으로 다름. 참고 프레임으로만 카탈로그에 포함.

## automation

- KIS API로 신용거래·선물·옵션 자동화는 현재 MumaeApp 어댑터 범위 밖. 나이/생애 마일스톤 기반의
  연 단위 리밸런싱이라 일 단위 자동화의 실익도 낮음 — **자동화 우선순위 최저**.

## backtest_notes

- 코어 6종 백테스터(일봉 루프, LOC/MOC/지정가 체결 모델)와 시간 스케일·자산군이 근본적으로 달라
  동일 프레임으로 백테스트하기 어려움 — 이번 프로젝트 범위에서는 **구현하지 않고 개요 조사로 종결**.

## 미확정/가정 항목

  마다 달라 "표준값"이 없음 — 이 문서는 저자들이 예시로 든 수치를 그대로 인용한 것.
